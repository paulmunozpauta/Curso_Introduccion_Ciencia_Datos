# Introducción a la Ciencia de Datos

Material oficial del curso **Introducción a la Ciencia de Datos** para las carreras de **Ingeniería Civil Agrícola** e **Ingeniería Ambiental** de la **Facultad de Ingeniería Agrícola, Universidad de Concepción**.

El curso introduce los fundamentos de la ciencia de datos mediante actividades prácticas utilizando **Google Colab**, permitiendo que los estudiantes desarrollen habilidades para organizar, analizar, visualizar e interpretar datos sin necesidad de instalar software en sus computadores.

---

## ¿Cómo utilizar este repositorio?

1. Abra el notebook correspondiente al módulo.
2. Haga clic en **Open in Colab** o abra el notebook directamente desde Google Colab.
3. Ejecute las celdas en el orden propuesto.
4. Guarde una copia del notebook en su Google Drive si desea conservar su trabajo.

## Contenidos del curso

### Módulo 1. Introducción a la Ciencia de Datos
- Introducción al curso
- Google Colab y Jupyter Notebook
- Conceptos básicos de Python
- Primeros pasos en el análisis de datos

### Módulo 2. Preparación de Datos
- Organización de archivos y directorios
- Importación y exportación de datos
- DataFrames
- Limpieza y preprocesamiento de datos

### Módulo 3. Exploración y Visualización de Datos
- Estadística descriptiva
- Histogramas
- Series de tiempo
- Diagramas de dispersión
- Boxplots
- Análisis exploratorio de datos

### Módulo 4. Análisis de Datos
- Correlación
- Regresión lineal
- Tendencias y estacionalidad
- Predicciones básicas

### Módulo 5. Introducción al Aprendizaje Automático
- Árboles de decisión
- Clasificación
- Clustering
- Aplicaciones en ingeniería agrícola y ambiental

### Módulo 6. Proyecto Integrador
Aplicación de las herramientas aprendidas a un conjunto de datos reales mediante el desarrollo de un proyecto práctico.
